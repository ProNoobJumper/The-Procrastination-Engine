# Clock-of-Clocks

*It's time... within a time... within a time.*

Welcome to **Clock-of-Clocks**, the only digital clock that has an identity crisis. Why have one clock when you can have hundreds working in perfect, synchronized harmony? Conceived from a moment of profound procrastination, this project answers the question nobody asked: "What if my clock was made of more, smaller clocks?"

## How It Works

The goal is beautifully simple: to tell you the current time. But the execution is where the madness lies.

* **The Grid:** Each number is formed by a 6x4 grid of tiny, individual clocks.
* **The Hands:** Every tiny clock has two hands that spin and lock into position to form a segment of a larger digit. It's like a tiny, well-rehearsed acrobat troupe, but for telling time.
* **The Brains:** A slick TypeScript engine calculates the correct hand positions for each clock based on the current time and updates them every second.

## Features

* **Tells Time:** Shockingly, yes. It accurately displays hours, minutes, and seconds.
* **Mesmerizing Animation:** The hands of each tiny clock transition smoothly, creating a visual spectacle with every passing second.
* **Intricate Digit Design:** The patterns that form each number are a work of art, proving that even something as mundane as time can be beautiful.
* **Fully Customizable:** Built with standard HTML, CSS, and TypeScript, you can tweak, style, and modify it to your heart's content. Go ahead, make the hands rainbow-colored. We won't judge.
